## 振り返り

今日見たものを並べます。

| 見たこと | 名前 |
|---|---|
| モデルとツールを交互に呼ぶループが回っている | エージェント |
| 関数を書いて説明文を付けると、モデルがそれを選んで呼ぶ | ツール |
| 質問をまたぐと忘れる。前のやりとりを保存して次に渡す仕組みが要る | Memory |
| 手元のエージェントを 1 行でクラウドに載せ、同じ画面から呼べる | Runtime |

もう 1 つ、今日は使わなかった名前を出しておきます。Gateway です。今日のツールは自分の Python の中にありましたが、実際には社内の API や他社のサービスをツールとして使いたくなります。そういう外のものをツールの形に揃えて、認証も含めて面倒を見るのが Gateway です。次に調べる取っかかりにしてください。

## 片付け

最後に、自分がデプロイしたものを自分で消します。クラウドは消すまで残るからです。

<Steps>

1. ターミナルで次の 2 行を順に打ちます。

   ```bash
   agentcore remove all
   agentcore deploy
   ```

2. 1 行目で設定が空になり、2 行目が空になったことを検知して AWS 側のリソースを撤去します。数分かかります。

</Steps>

:::caution[remove all は必ず最後に]
`remove all` のあとは同じ環境で deploy し直せません。もう一度 Runtime で試したいことがあれば、その前に済ませてください。
:::

消し忘れがあっても主催者が後でまとめて片付けるので、終わるのを待たずに退出して大丈夫です。

お疲れさまでした。
