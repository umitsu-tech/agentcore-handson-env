自分で直せないときは、迷わず主催者に声をかけてください。

## エディタのパスワードが通らない

配られた URL とパスワードの組み合わせを確認してください。`userNN` の番号が自分のものか見てください。他の人の URL に自分のパスワードを入れても通りません。

## ハンズオン UI が開かない

先にエディタにログインしてから、UI の URL を開いてください。UI はエディタ経由で表示されます。

エディタにログインしているのに開かないときは、ページを再読み込みしてください。

## 質問を送ったのに何も出ない、エラーになる

ページを再読み込みしてから、もう一度送ってください。それでも出ないときは、`tools.py` か `agent.py` の保存で構文エラーが起きていて、裏のサーバーが起動できていないことが多いです。エディタの赤線を見てください。

## ツールを足したのに一覧に出ない

3 つ確認してください。

1. `tools.py` と `agent.py` の両方を保存したか
2. `agent.py` の `TOOLS` に足したか
3. エディタに赤線が出ていないか

保存すると裏のサーバーが再起動します。数秒待ってから「モデルに渡しているもの」を開き直してください。

## 足したツールが呼ばれない

説明文（docstring）を読み直してください。モデルは説明文を見てツールを選びます。質問の言葉と説明文の言葉が近いほど選ばれやすくなります。

## agentcore deploy が失敗した

もう一度同じコマンドを打つと、続きから進むことが多いです。それでも止まるときは、ターミナルの最後の数行を主催者に見せてください。

ターミナルを開いた場所が `/home/handson/workspace` になっているかも確認してください。`handson-agent/` の中で打つと失敗します。

## Runtime に切り替えると失敗する

deploy が終わったあとに UI のページを再読み込みしたか確認してください。deploy の途中で切り替えると失敗します。
