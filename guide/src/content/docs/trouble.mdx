自分で直せないときは、迷わず主催者に声をかけてください。

## エディタのパスワードが通らない場合

配られた URL とパスワードの組み合わせを確認してください。`userNN` の番号が自分のものか見てください。他の人の URL に自分のパスワードを入れても通りません。

## ハンズオン UI が開かない場合

先にエディタにログインしてから、UI の URL を開いてください。UI はエディタ経由で表示されます。

エディタにログインしているのに開かないときは、ページを再読み込みしてください。

## 質問を送っても何も出ない場合

ページを再読み込みしてから、もう一度送ってください。それでも出ないときは、主催者に声をかけてください。

## ハンズオン UI の上に赤い枠でエラーが出た場合

「エージェントのコードを読み込めませんでした」と出ていたら、`tools.py` か `agent.py` に書き間違いがあります。枠の中に、どのファイルの何行目かが書いてあります。そこを直して保存し、ページを再読み込みしてください。

よくある原因は 2 つです。

1. `TOOLS` の途中の行のカンマ抜け（`SyntaxError: invalid syntax. Perhaps you forgot a comma?`）
2. `tools.py` を保存する前に `agent.py` を保存した（`AttributeError: module 'tools' has no attribute 'find_available'`）。`tools.py` を保存すれば直ります

## 「モデルの呼び出しが混み合っています」と出た場合

画面にこのメッセージが出たら、少し待ってからもう一度同じ質問を送ってください。他の受講者と質問のタイミングが重なっただけで、こちらの操作に問題はありません。ステップ 1〜4 のどこでも起こりえます。

## 足したツールが一覧に出ない場合

3 つ確認してください。

1. `tools.py` と `agent.py` の両方を保存したか。エディタのタブのファイル名の右に `●` が残っていたら、まだ保存できていません
2. `agent.py` の `TOOLS` の `# tools.find_available,` のコメントを外したか
3. ハンズオン UI の上に赤い枠のエラーが出ていないか

保存すると裏のサーバーが再起動します。数秒待ってからページを再読み込みし、「モデルに渡しているもの」を開き直してください。

## 足したツールが呼ばれない場合

説明文（docstring）を読み直してください。モデルは説明文を見てツールを選びます。質問の言葉と説明文の言葉が近いほど選ばれやすくなります。

## agentcore deploy が失敗する場合

もう一度同じコマンドを打つと、続きから進むことが多いです。それでも止まるときは、ターミナルの最後の数行を主催者に見せてください。

ターミナルを開いた場所が `/home/handson/workspace` になっているかも確認してください。`handson-agent/` の中で打つと失敗します。

## Runtime への切り替えで失敗する場合

deploy が終わったあとに UI のページを再読み込みしたか確認してください。deploy の途中で切り替えると失敗します。
