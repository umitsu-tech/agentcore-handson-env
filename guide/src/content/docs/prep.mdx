受講者ごとに、専用の環境が 1 台ずつ用意してあります。配られる情報は 3 つです。

| 配られるもの | 何に使うか |
|---|---|
| エディタの URL | `https://userNN.handson.example.com` の形。ブラウザで開く VS Code です |
| ハンズオン UI の URL | エディタの URL の後ろに `/proxy/3000/` が付いた形。エージェントの動きを見る画面です |
| パスワード | エディタを開いたときに 1 回だけ聞かれます |

`userNN` の番号は人ごとに違います。自分の番号のものを使ってください。

## アクセスの手順

<Steps>

1. エディタの URL をブラウザで開きます。パスワードを聞かれるので、配られたものを入れます。

2. `workspace` というフォルダが開いた状態で始まり、README が表示されます。左側にフォルダが 3 つ見えます。

   | フォルダ | 役割 |
   |---|---|
   | `handson-agent/` | 今日触るファイルはここだけです |
   | `handson-ui/` | 主催者側の画面。触りません |
   | `agentcore/` | デプロイ用の設定。触りません |

3. ハンズオン UI の URL を別のタブで開きます。「エージェントの動きを見る」という画面が出れば準備完了です。

</Steps>

:::caution[UI を開く順番]
UI はエディタ経由で表示されます。先に UI の URL を開くとエディタのログイン画面に飛ばされるので、順番だけ守ってください。
:::

## 環境の全体像

自分のブラウザから、自分専用のサーバー（EC2）に届いています。エディタも UI もその上で動いています。

![環境の構成図。ブラウザから ALB を経由して受講者ごとの EC2 に届き、EC2 から Bedrock と AgentCore Runtime を呼ぶ](/images/architecture.png)

前半はこの EC2 の上でエージェントが動きます。後半で、それを AgentCore Runtime に載せ替えます。
