受講者ごとに、専用の環境が 1 台ずつ用意してあります。使う情報は 3 つで、この手順書の「受講者情報」のページに載っています。

| 使うもの | 何に使うか |
|---|---|
| エディタの URL | `https://userNN.handson.example.com` の形。ブラウザで開く VS Code です |
| ハンズオン UI の URL | エディタの URL の後ろに `/proxy/3000/` が付いた形。エージェントの動きを見る画面です |
| パスワード | エディタを開いたときに 1 回だけ聞かれます |

`userNN` の番号は人ごとに違います。自分の番号は当日、主催者から伝えます。

## アクセスの手順

<Steps>

1. 左のメニューの一番下にある「受講者情報（合言葉が要る）」を開きます。ユーザー名と合言葉を聞かれるので、当日その場で伝えるものを入れます。

2. 「自分の番号で絞り込む」に自分の番号（`07` など）を入れます。自分の行に色が付き、エディタの URL、ハンズオン UI の URL、パスワードが並びます。

   ![受講者情報のページ。番号で絞り込むと自分の行に色が付き、エディタの URL、ハンズオン UI の URL、パスワードとコピーボタンが並ぶ](/images/participants.png)

   このページはあとで URL を見返すので、開いたままにしておいてください。

3. 自分の行の「エディタの URL」を押すと、新しいタブでエディタが開きます。パスワードを聞かれるので、受講者情報のページの「コピー」ボタンでコピーしたものを貼り付けます。

4. `workspace` というフォルダが開いた状態で始まり、README が表示されます。左側にフォルダが 3 つ見えます。

   | フォルダ | 役割 |
   |---|---|
   | `handson-agent/` | 今日触るファイルはここだけです |
   | `handson-ui/` | 主催者側の画面。触りません |
   | `agentcore/` | デプロイ用の設定。触りません |

5. 受講者情報のページに戻り、自分の行の「ハンズオン UI の URL」を押します。新しいタブで「エージェントの動きを見る」という画面が出れば準備完了です。

</Steps>

:::caution[UI を開く順番]
UI はエディタ経由で表示されます。先に UI の URL を開くとエディタのログイン画面に飛ばされるので、順番だけ守ってください。
:::

## 環境の全体像

自分のブラウザから、自分専用のサーバー（EC2）に届いています。エディタも UI もその上で動いています。前半はこの EC2 の上でエージェントが動き、後半でそれを AgentCore Runtime に載せ替えます。

![受講環境の全体像。ブラウザのエディタとハンズオン UI のタブが、自分専用の EC2 の中のエディタとハンズオン UI につながる。UI がエージェントを呼び、エージェントが Amazon Bedrock のモデルを呼ぶ。ステップ 4 でエージェントを AgentCore Runtime に載せる](/images/environment-overview.png)
