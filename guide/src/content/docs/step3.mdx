---
title: 3. 会話の継続
description: 続けて質問すると、少し前に言ったことをエージェントが忘れます。ここで Memory の名前を出します
---

続けて 2 回、3 回と質問してみてください。

```text
モニター借りたいんだけど
```

```text
それ誰が借りてるの？
```

2 つ目の質問で、エージェントは「それ」が何のことか分かりません。前の質問を覚えていないからです。

## 忘れる理由

![質問をまたぐとモデルには何も残らない。2 つ目の質問の入力には 1 つ目の質問も答えも入っていない。覚えさせるには前のやりとりを保存して次に渡す必要があり、それを引き受けるのが AgentCore Memory](/images/memory.png)

画面の「モデルに渡しているもの」をもう一度見てください。渡しているのは、システムプロンプトとツールの一覧と、今回の質問だけです。前の質問も、前の答えも入っていません。

1 つの質問の中では、1 周目の結果を 2 周目に渡しているので覚えています。でも質問が変わると、まっさらな状態から始まります。モデルそのものには何も残りません。

覚えさせたければ、前のやりとりを自分で保存しておいて、次の質問のときに一緒に渡す必要があります。誰が話したか、どこまで渡すか、古いものをいつ捨てるか。全部自分で面倒を見ることになります。

## AgentCore Memory の役割

この「前のやりとりを保存して、次に渡す」を引き受けるのが AgentCore Memory です。今日は名前だけ覚えて帰ってください。

:::note[今日の範囲]
Memory を組み込むところまではやりません。「会話を続けたら忘れた。だから Memory がある」という順番で、名前と困りごとが結びついていれば十分です。
:::
