ツールは「関数」です。自分で足した関数がモデルから呼ばれる瞬間を見ます。

## 既存のツール

エディタで `handson-agent/tools.py` を開きます。`@tool` の付いた関数が 2 つあります。さっき呼ばれた `search_equipment` と、備品 ID で貸出状況を調べる `get_equipment_status` です。

```python title="handson-agent/tools.py（抜粋）"
@tool
def search_equipment(keyword: str) -> list[dict]:
    """備品を名前やカテゴリで検索する。

    Args:
        keyword: 検索したい言葉。「ノートPC」「モニター」など

    Returns:
        見つかった備品のデータの一覧（id, name, category, status, borrower, due_date）。
        見つからなければ空リスト
    """
    return [
        item
        for item in _load_equipment()
        if keyword in item["name"] or keyword in item["category"]
    ]
```

![ツールの関数のどこがモデルに渡るか。@tool、関数名と引数、説明文がモデルに渡り、戻り値はデータのまま返す](/images/tool-anatomy.png)

モデルに渡っているのは、関数名、引数の名前と型、そして説明文（docstring）です。ハンズオン UI の「モデルに渡しているもの」に出ていたのはこれです。モデルは説明文を読んで「今の質問にはこのツールが要る」と判断しています。

ツールは文章ではなくデータ（dict や list）を返します。日本語の文章にするのはモデルの仕事です。

## 追加するツール

「モニター借りたいんだけど空いてる？」と聞かれたときに、いま借りられるものだけを返すツールを足します。中身はもう書いてあり、コメントになっています。コメントを外すだけで使えます。

<Steps>

1. `tools.py` の一番下を見ます。`find_available` という関数がコメントになっています。`# @tool` の行から最後の `#     ]` の行までをマウスで選び、`Ctrl + /`（Mac は `Cmd + /`）を押します。行の先頭の `#` が外れて、次の形になります。

   ```python title="handson-agent/tools.py（一番下）"
   @tool
   def find_available(category: str) -> list[dict]:
       """指定したカテゴリで、いま貸出可能な備品を探す。

       Args:
           category: 「ノートPC」「モニター」などのカテゴリ名

       Returns:
           貸出可能な備品のデータの一覧（id, name, category, status, borrower, due_date）
       """
       return [
           item
           for item in _load_equipment()
           if item["category"] == category
           and item["status"] == "貸出可"
       ]
   ```

   ショートカットが効かないときは、左上のメニュー（☰）の Edit → Toggle Line Comment でも外せます。

2. `tools.py` を保存します。`Ctrl + S`（Mac は `Cmd + S`）か、左上のメニュー（☰）の File → Save です。

3. `handson-agent/agent.py` を開きます。`TOOLS` の 3 行目にある `# tools.find_available,` を、同じように `Ctrl + /` でコメントを外して保存します。ここに並べたものだけがモデルから見えます。

   ```python title="handson-agent/agent.py" ins={4}
   TOOLS = [
       tools.search_equipment,
       tools.get_equipment_status,
       tools.find_available,
   ]
   ```

4. ハンズオン UI のページを再読み込みして、「モデルに渡しているもの」を開きます。ツールが 3 つに増えています。

5. もう一度質問を送ります。

   ```text
   モニター借りたいんだけど空いてる？
   ```

   1 周目のオレンジのカードで、自分の `find_available` が呼ばれるところを見てください。

</Steps>

:::note[保存できたかの確かめ方]
保存していないファイルは、エディタの上のタブに色の線が付き、ファイル名の右に `●` が出ます。保存すると消えます。

UI のサーバーは `handson-agent/` のファイルを見張っていて、保存すると再起動して新しいツールを読み込みます。数秒かかるので、一覧が増えないときは少し待ってからページを再読み込みしてください。

`tools.py` を先に保存してください。`agent.py` を先に保存すると、まだ無いツールを探して、下の赤い枠のエラーが出ます。
:::

:::caution[画面の上に赤い枠でエラーが出た場合]
保存したファイルに書き間違いがあると、ハンズオン UI の上に「エージェントのコードを読み込めませんでした」と出ます。どのファイルの何行目かが書いてあるので、そこを直して保存し、ページを再読み込みしてください。

よくあるのは、`TOOLS` の途中の行のカンマ抜けと、`tools.py` を保存する前に `agent.py` を保存した場合です。
:::

## ツールが呼ばれない場合

モデルは説明文を見てツールを選んでいます。呼ばれなければ、説明文を読み直してみてください。「いま貸出可能な」という言葉が入っていれば、「空いてる？」という質問に結びつきやすくなります。

:::tip[余裕があれば]
ツールの名前や説明文を変えて、モデルの選び方が変わるかを試してみてください。説明文を「備品を探す」だけにすると、`search_equipment` との使い分けができなくなって、どちらが呼ばれるかが揺れます。説明文がモデルへの指示になっている、という感覚をつかんでください。
:::
