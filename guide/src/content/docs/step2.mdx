ツールは「関数」です。自分で書いた関数がモデルから呼ばれる瞬間を見ます。

## 既存のツール

エディタで `handson-agent/tools.py` を開きます。`@tool` の付いた関数が 2 つあります。さっき呼ばれた `search_equipment` と、備品 ID で貸出状況を調べる `get_equipment_status` です。

```python title="handson-agent/tools.py（抜粋）"
@tool
def search_equipment(keyword: str) -> list[dict]:
    """備品を名前やカテゴリで検索する。

    Args:
        keyword: 検索したい言葉。「ノートPC」「モニター」など

    Returns:
        見つかった備品のデータの一覧（id, name, category, status, borrower, due_date）。
        見つからなければ空リスト
    """
    return [
        item
        for item in _load_equipment()
        if keyword in item["name"] or keyword in item["category"]
    ]
```

![ツールの関数のどこがモデルに渡るか。@tool、関数名と引数、説明文がモデルに渡り、戻り値はデータのまま返す](/images/tool-anatomy.png)

モデルに渡っているのは、関数名、引数の名前と型、そして説明文（docstring）です。ハンズオン UI の「モデルに渡しているもの」に出ていたのはこれです。モデルは説明文を読んで「今の質問にはこのツールが要る」と判断しています。

ツールは文章ではなくデータ（dict や list）を返します。日本語の文章にするのはモデルの仕事です。

## 追加するツール

「モニター借りたいんだけど空いてる？」と聞かれたときに、いま借りられるものだけを返すツールを足します。`tools.py` の一番下にコメントで雛形が書いてあるので、それを参考にしてください。

<Steps>

1. `tools.py` の一番下に、次の関数を書きます。

   ```python title="handson-agent/tools.py（一番下に足す）"
   @tool
   def find_available(category: str) -> list[dict]:
       """指定したカテゴリで、いま貸出可能な備品を探す。

       Args:
           category: 「ノートPC」「モニター」などのカテゴリ名

       Returns:
           貸出可能な備品のデータの一覧（id, name, category, status, borrower, due_date）
       """
       return [
           item
           for item in _load_equipment()
           if item["category"] == category
           and item["status"] == "貸出可"
       ]
   ```

2. `handson-agent/agent.py` を開き、`TOOLS` の一覧に足します。ここに並べたものだけがモデルから見えます。

   ```python title="handson-agent/agent.py" ins={4}
   TOOLS = [
       tools.search_equipment,
       tools.get_equipment_status,
       tools.find_available,
   ]
   ```

3. 両方のファイルを保存します。ハンズオン UI の「モデルに渡しているもの」を開き直すと、ツールが 3 つに増えています。

4. もう一度質問を送ります。

   ```text
   モニター借りたいんだけど空いてる？
   ```

   1 周目のオレンジのカードで、自分の `find_available` が呼ばれるところを見てください。

</Steps>

:::note[保存時のサーバー再起動]
UI のサーバーは `handson-agent/` のファイルを見張っていて、保存すると再起動して新しいツールを読み込みます。数秒かかるので、一覧が増えないときは少し待ってから開き直してください。
:::

## ツールが呼ばれない場合

モデルは説明文を見てツールを選んでいます。呼ばれなければ、説明文を読み直してみてください。「いま貸出可能な」という言葉が入っていれば、「空いてる？」という質問に結びつきやすくなります。

:::tip[余裕があれば]
ツールの名前や説明文を変えて、モデルの選び方が変わるかを試してみてください。説明文を「備品を探す」だけにすると、`search_equipment` との使い分けができなくなって、どちらが呼ばれるかが揺れます。説明文がモデルへの指示になっている、という感覚をつかんでください。
:::
