ここまで、エージェントは自分の EC2 の上で動いていました。それを AWS のマネージド環境（AgentCore Runtime）に載せ替えます。

## やること

<Steps>

1. エディタのメニューから Terminal → New Terminal でターミナルを開きます。`/home/handson/workspace` が開いた状態になっています。この場所のまま打ちます。

2. 次の 1 行を打ちます。

   ```bash
   agentcore deploy
   ```

3. 2〜3 分かかります。その間に、Runtime が何を引き受けてくれるのかの話を聞いてください。ターミナルに `Deployed` のような表示が出て止まったら終わりです。

4. ハンズオン UI のページを再読み込みします。入力欄の上に「手元で動かす / Runtime で動かす」の切り替えが増えています。

5. 「Runtime で動かす」に切り替えて、前半と同じ質問を送ります。

   ```text
   モニター借りたいんだけど空いてる？
   ```

</Steps>

## 見比べてほしいこと

![前半は自分の EC2 の中でエージェントが動き、後半は同じコードが AgentCore Runtime の中で動く。ブラウザと UI のサーバーは変わらない](/images/local-vs-runtime.png)

画面の見え方は前半とまったく同じです。緑のカードに「お題（Runtime）」と出ているところだけが違います。

自分で書いた `find_available` も、そのまま Runtime 側で呼ばれます。載せたのは、さっきまで手元で動いていた自分のエージェントそのものです。

違うのは動いている場所だけです。前半は自分の EC2 の中で Python が動いていました。今は AWS 側の箱の中で同じコードが動き、EC2 はそれを呼びに行っているだけです。

## Runtime が引き受けているもの

手元で動いているものを他の人に使ってもらうには、いろいろ要ります。サーバーを立てて、認証を付けて、同時にたくさん来ても耐えて、落ちたら上げ直す。それを全部引き受けるのが Runtime です。

いま打ったのは 1 行でしたが、裏では自分のコードがコンテナに詰められ、実行用の権限が作られ、呼び出し口が用意されました。前半のループのコードは 1 行も変わっていません。

:::note[deploy が失敗したら]
もう一度同じ `agentcore deploy` を打つと、続きから進むことが多いです。それでも止まるときは、ターミナルの最後の数行を主催者に見せてください。
:::
