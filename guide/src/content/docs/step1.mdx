import { Steps } from '@astrojs/starlight/components';

まずは用意してあるエージェントをそのまま動かします。目標は「エージェントの中で何が起きているか」を目で見ることです。

## 手順

<Steps>

1. ハンズオン UI の上にある「モデルに渡しているもの」を開いてみてください。モデルへの指示（システムプロンプト）と、使えるツールの一覧が見えます。モデルはこれを毎回受け取っています。

2. 入力欄に質問を入れて「送る」を押します。まずはこれを試してください。

   ```text
   モニター借りたいんだけど
   ```

   入力欄の下にある例文を押しても同じことができます。

3. 画面に、モデルとのやりとりが上から順に流れます。止まるまで待ってから、上から読んでみてください。

</Steps>

## 画面の読み方

![質問を送ったあとの画面。1 周目でモデルがツールを呼び、ツールが結果を返している](/images/ui-loop-top.png)

カードの色は 3 つだけです。

| 色 | 意味 |
|---|---|
| 緑 | ループの入口と出口。あなたの質問（お題）と、最終的な答え |
| 青 | モデルに入るもの（インプット） |
| オレンジ | モデルかツールから出てくるもの（アウトプット） |

「1 周目」「2 周目」という見出しで区切ってあります。1 周は「モデルを呼んで、ツールを実行して、結果を受け取るまで」です。

1 周目では、あなたの質問とツールの一覧がモデルに渡り、モデルが「`search_equipment` をこの引数で呼んで」と返してきます。それを受けてツールが実行され、備品のデータが返ります。

![2 周目でツールの結果がモデルに渡り、モデルが最終的な答えを書いている](/images/ui-loop-bottom.png)

2 周目では、ツールが返したデータが今度はモデルへの入力になります。周の境目で同じ内容のカードがオレンジから青に変わるのは、「出てきたものを次は入れる」ことを見せるためです。モデルはそれを読んで日本語の答えを書き、ツールを呼ばなかったのでループが止まります。

一番下の「このやりとりの中身」に、周回数、使ったトークン数、止まった理由、呼んだツールが出ます。

## ポイント

これがエージェントの中身です。魔法ではなく、モデルとツールを交互に呼ぶループが回っているだけです。

![エージェントの 1 回の実行。1 周目で質問とツールの一覧がモデルに渡り、モデルがツールを選び、ツールが結果を返す。2 周目でその結果がモデルに渡り、モデルが答えを書いてループが止まる](/images/loop-cycle.png)

モデルは文章を返すことしかできません。ツールを「呼んで」と言うだけで、実際に実行しているのは手元のプログラムです。その結果をもう一度モデルに渡すから、データに基づいた答えが返ってきます。

:::tip[追加の実験]
「PC-001って誰が借りてるの？」のように、別のツールが要る質問も送ってみてください。モデルが選ぶツールが変わります。備品に関係ない質問をすると、ツールを呼ばずに 1 周で終わります。
:::
